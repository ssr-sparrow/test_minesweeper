# 网页版扫雷

一个零依赖的原生网页扫雷游戏，支持自定义 `2–30` 行、`2–30` 列，以及 `0` 到满格数量的雷。

## 启动

```bash
python3 server.py
```

电脑访问 <http://127.0.0.1:8000>。

手机需要与电脑连接到同一个 Wi-Fi，然后访问服务器启动时显示的局域网地址，例如
`http://172.20.10.3:8000`。如果 macOS 弹出防火墙提示，需要允许 Python 接受传入连接。

## 操作

- 电脑：左键翻格，右键插旗。
- 手机：使用“翻格 / 插旗”模式切换后点击格子。
- 可设置左键在按下时立即翻格，或松开时翻格。
- 按住已翻开的数字会预览周围未翻格；旗数匹配时触发快捷翻开。
- 非满雷棋盘保证首次翻格安全；满雷棋盘首次翻格会直接失败。
